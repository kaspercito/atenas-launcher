Mods del modpack

Añadir mods

Solo salen mods que funcionan con la versión y el loader de tu pack. Si no está en Modrinth, prueba en CurseForge.

Conecta CurseForge (una sola vez)

CurseForge pide una API key gratuita: entra en console.curseforge.com, inicia sesión, ve a API keys, copia la tuya y pégala aquí. Se guarda cifrada en tu PC, nunca en GitHub.

Mis .jar

Para mods que no están en Modrinth. Arrastra los archivos aquí; se suben a GitHub al publicar.

⬇Suelta aquí tus .jaro

Ajustes del pack

Versión de Minecraft, Forge (u otro loader), memoria RAM y servidor. Se guarda en pack.json; después pulsa Publicar para que tus amigos lo reciban.

⚠ Si cambias la versión de Minecraft o del loader, revisa con Vista previa que tus mods sigan siendo compatibles antes de publicar.

Zona peligrosa

Borra este modpack de tu carpeta (y de GitHub si quieres). Desaparece del launcher de tus amigos; lo que ya tienen instalado se queda en sus PCs.

Publicar cambios

Descarga los mods, comprueba dependencias, genera el manifest y lo sube a GitHub. Tus amigos reciben el aviso solos.
